# Match Research — Android APK

Native Android starter app for your daily football and tennis research workflow.

## Features in this first build
- Native Android interface with Football and Tennis tabs.
- Manually add fixtures after checking reliable sources.
- Heuristic screening score out of 100 (not a calibrated probability).
- At most two selected fixtures per sport.
- Select a fixture before scheduling local Android notifications.
- Football second-half review and tennis follow-up reminders.
- Fixture data stored locally on the device.

## Get the APK
The GitHub Actions workflow builds a debug APK. Open the repository Actions tab, choose **Build Android APK**, open a successful run, and download the artifact **match-research-debug-apk**. The APK is inside that artifact. This build has not been verified until a successful workflow run completes.

## Not connected yet
Live fixtures, current stats/odds feeds, Google Calendar OAuth, and automatic daily refresh are not included yet. Reminders are local device notifications. Verify event details and current information yourself. The app does not place bets or guarantee outcomes.
